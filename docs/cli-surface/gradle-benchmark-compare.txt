Usage: gradle-benchmark compare [<options>]

  Compare two run.json files and report what changed.

Options:
  --output-dir=<path>       Directory for generated artifacts (default:
                            build/gradle-benchmark).
  --gradle-profiler=<text>  Path to the gradle-profiler executable.
  --baseline=<path>         run.json treated as the baseline.
  --candidate=<path>        run.json treated as the candidate.
  --measurement=<text>      Which measured quantity to compare.
  -h, --help                Show this message and exit
