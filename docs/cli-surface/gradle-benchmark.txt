Usage: gradle-benchmark [<options>] <command> [<args>]...

  Regression testing for Gradle build performance.

Options:
  -h, --help  Show this message and exit

Commands:
  validate  Validate scenario selection, configuration, and required tooling.
  run       Run a benchmark and write run.json, plus a comparison when variants
            are compared.
  compare   Compare two run.json files and report what changed.
  help      Show usage for the tool or a command.
